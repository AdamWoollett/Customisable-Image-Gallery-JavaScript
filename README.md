# Customisable Image Gallery

## Overview
Customisable Image Gallery is a web page with the functionality for a user to add any images to the gallery on the page if they have a URL for the image they can input into the Input Image URL box.<br>
Submitted images will then be displayed on the page in a dedicated bounding box for each image.<br>
Individual images added to the page can be removed using the "Remove Image" button that accompanies each image.<br>
A preview of what this project looks like when deployed can be viewed on Vercel at this link: https://customisable-image-gallery.vercel.app/

## Tech Stack
- JavaScript
- HTML5
- CSS3
